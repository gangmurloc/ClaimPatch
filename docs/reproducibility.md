# Reproducibility

## CPU path

The deterministic benchmark is fully generated from its YAML configuration:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
decap run-p0 --config configs/experiments/p0_rule_based.yaml
pytest -q
```

Outputs are written beneath `outputs/`, which is ignored by Git except for its
placeholder.

## Structured mock path

```bash
decap run-p1 --config configs/experiments/p1_prompted.yaml --limit 4
```

This verifies prompt rendering, JSON extraction, Pydantic validation, schema
repair, transactional execution, and reporting without downloading an LLM.

## Local-model path

```bash
pip install -e ".[dev,local]"
CUDA_VISIBLE_DEVICES=0 sh scripts/run_p1_local_full100x3.sh
```

The provided model configurations use local Hugging Face files and deterministic
decoding. Hardware, installed package builds, and model availability affect
runtime. Model weights are not redistributed.

## Artifact boundary

The repository includes aggregate summaries and machine-readable metrics, not
raw generations. Exact reproduction of the reported local-model run requires
the named model checkpoint and a compatible local Transformers environment.
The synthetic benchmark itself is regenerated by code; no private dataset is
required.
