Task: executable semantic patch generation.

Generate the smallest schema-valid SemanticPatch that handles every
MUST_CHANGE claim and preserves STILL_VALID claims. Use only allowed
operations: REPLACE, DELETE, INSERT, SPLIT, MERGE, REBIND, INVALIDATE.

Rules:
- Include preconditions for touched and preserved active claims.
- Do not rewrite preserved claims.
- New or rebound claims must use evidence IDs that exist in the fresh target.
- Return JSON only with key "semantic_patch".
- For REPLACE, include exactly one full replacement ClaimNode in `new_claims`.
- The replacement ClaimNode must be copied from `fresh_target.claims` using the
  same `claim_id` as the old claim.
- For REBIND, keep `new_claims` empty and set `new_evidence_ids`.
- Every operation must include a non-empty `reason`.
- `dependency_updates` is optional. Prefer `dependency_updates: []` unless a
  dependency edge truly changes. If you include dependency updates, every edge
  must include `source_claim_ids`, `target_claim_id`, `dependency_type`,
  `confidence`, `rule`, and `metadata`.
